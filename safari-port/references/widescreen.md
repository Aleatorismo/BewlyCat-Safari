# Bewly 宽屏定制与回归

已选择并确认正常使用的定制：隐藏宽屏底部弹幕发送栏，同时保留右侧详情/评论抽屉。升级此定制版本时保留该选择；它是用户功能偏好，并非所有 Safari 转换都必须应用的修复。

## 隐藏发送栏并回收空间（1.8.0.5，构建 7）

用户首先希望用普通网页全屏替换 Bewly 自有布局，但允许在无法简单替换时隐藏发送栏。1.8.0 的 `yre` 点击监听会在进入原生网页全屏时调用 `yo` 退出 Bewly 布局，因此未采用直接替换。最终只追加以下外部内容 CSS：

```css
/* Bewly widescreen: hide the sender dock; its ResizeObserver reclaims the
   measured height for the player and keeps the existing drawer layout intact. */
#bewly-widescreen-root .bewly-widescreen-danmaku-dock {
  display: none !important;
}
```

原始布局把发送控件搬进独立 dock；`hI` 读取 dock 高度，更新 `--bewly-widescreen-danmaku-height`。既有 ResizeObserver 会观察它，隐藏后测得 0，播放器高度 `calc(100dvh - var(--bewly-widescreen-danmaku-height, 0px))` 自动填满可用空间。不要只设 opacity/visibility，不要硬编码扣掉若干像素，也不要移除原始发送节点，否则会遗留空白或破坏退出后的恢复。新版用语义定位，压缩函数名只作历史线索。

保留原来的两种抽屉行为：`fit` 模式悬停屏幕右侧边缘展开，覆盖视频而不缩小视频；点击 `.bewly-widescreen-sidebar-toggle` 切到 `narrow` 固定模式，侧栏占据独立列，视频可用宽度缩小。退出 Bewly 宽屏后发送栏应在普通页面恢复。不要为此重写抽屉状态机或改变 B 站原生网页全屏行为。

## 抽屉灰底上的黑色评论块（1.8.0.6，构建 8）

这是早期评论修复没有区分容器造成的回归。最终背景 CSS 位于 [兼容修复手册](compatibility.md#评论背景应跟随所在容器)，以那里为唯一实现来源。宽屏评论应跟随 `--bewly-widescreen-sidebar-bg`，普通页回退 `--bew-bg`。两个变量的实际颜色不相同，不要把整个抽屉强制改黑来掩盖问题。

## 已验证行为与今后的验证方法

2026-10-04 在 Safari 视频页、1202 × 797 CSS 像素完整视口下：

| 状态 | 播放器尺寸 | 抽屉位置与宽度 | 发送栏高度 |
| --- | --- | --- | --- |
| 收起 | 1202 × 797 | x=1202，宽 480，在屏外 | 0 |
| 边缘悬停展开 | 1202 × 797 | x=722，宽 480，覆盖视频 | 0 |
| 箭头固定 | 842 × 797 | x=842，宽 360，与视频并列 | 0 |
| 取消固定并离开 | 1202 × 797 | 回到屏外 | 0 |

悬停路径用页面 PointerEvent 模拟触发，箭头调用现有按钮 click；另有 Safari 目测和退出宽屏后的原生 UI 检查。不要把这些精确尺寸当成其它窗口的硬指标，重点是填满高度、覆盖与并列关系，以及恢复行为。

暗色背景实测：抽屉评论宿主、内部 `#body`、抽屉面板均为 `oklab(0.331374 -0.001536 -0.009391)`；退出后新生成的评论宿主、`#body` 与普通页面均为 `oklab(0.236947 -0.001294 -0.007909)`。刷新后及重新进入宽屏后的目测通过。当前用户也确认使用正常。

调试注意：

- Safari 检查器停靠会改变网页视口高度，测试完整布局时先关闭检查器，或在关闭导致 resize 后读取尺寸。
- 评论位于多层 Shadow DOM，需要递归遍历开放 shadowRoot。切换模式可能销毁并新建评论节点；每次重新查询并检查 `isConnected`，不要读取旧节点的空样式作为成功证据。
- 评论按可见区域延迟加载；检查器压缩视口时可能一直显示“正在玩命加载”。关闭检查器、滚动到评论后再检查，有限重试；未加载不等于颜色规则失效。
- 控制台粘贴可能报剪贴板超时但文字已输入；先核对提示区再按回车，勿盲目追加命令。此前 `typeText` 丢过括号，不当作可靠替代。
- 调试后关闭检查器，恢复用户原本的主题、抽屉状态及视频时间/暂停状态。移动播放器节点后暂停画面偶尔变黑，可短暂播放再暂停确认重绘，无需刷新整个页面。

升级回归同时覆盖普通页与宽屏、固定与悬停、退出与重新进入、刷新后的持久效果；检查文字可读及输入框/徽章/图片正常。还应检查亮色，但如无法现场验证要明确说明，勿从 CSS 推断测试结果。
